# 洋哥做题了

**一款面向家庭的 Android 学习辅助应用：家长设置手机使用时间，孩子通过答题完成学习练习。**

儿童手机运行应用，家长通过手机或电脑上的网页管理。家长网页由儿童手机在局域网内提供；AI 出题等功能需要连接互联网和阿里云百炼。

> 本项目在 AI 工具辅助下开发。应用适合家长与孩子共同约定学习和使用手机的规则。

## 核心功能

| 功能 | 能做什么 |
| --- | --- |
| ⏱️ 整机使用计时 | 家长设置每轮使用时长和每轮题数；时间到后弹出答题窗口。熄屏或锁屏时暂停计时。 |
| 📝 答题与错题 | 孩子答题时可查看分步提示；系统记录出现、答对、答错和超时情况，支持错题复习。 |
| 🎯 50 题刷题 | 家长可手动发起或设置定时刷题，页面显示完成进度；未完成的练习可继续。 |
| 📅 定时任务 | 设置特定时段的定时弹题、到点开始 50 题刷题，或在指定时段暂停管控。 |
| 🤖 AI 题库 | 使用通义千问按教材章节生成题目，也可导入图片或 WPS 文档中的题目。 |
| 📚 教材知识库 | 内置部分六年级上册知识库，也支持家长批量上传 Markdown 文件，添加其他年级、学科和章节。 |
| 📱 应用管理 | 设置白名单和黑名单；白名单应用不计时，打开黑名单应用时触发答题挑战。 |
| 👪 家人协助 | 生成可撤销的分享链接，让家人在简化页面查看状态并进行指定操作。 |

## 怎么使用

### 第一步：准备儿童手机

1. 在儿童手机上安装应用，设置家长密码。
2. 在**家长设置 → 权限和后台运行**中，开启“使用情况访问”和“显示在其他应用上层”。需要设置保护或答题防下拉时，可按提示开启对应的无障碍服务。
3. 根据手机系统的电池和后台管理设置，允许应用在后台运行。不同厂商的设置位置和限制可能不同。
4. 在“连接家长手机”中查看网页地址或二维码；家长设备与儿童手机连接同一局域网后打开，按页面提示输入家长密码。

应用的桌面图标默认隐藏。全新安装后，可通过 ADB 打开儿童端设置页：

```sh
adb shell am start -n cn.tan.watchgate/.MainActivity
```

### 第二步：准备题库

1. 如需使用 AI 出题，在儿童手机的家长设置中配置自己的阿里云百炼 API Key。
2. 在家长网页的**题库生成**中选择年级、学科、册别和教材章节，然后点击“生成”。也可以选择图片或 WPS 文档进行导入；每次最多选择 4 张图片。
3. 在**AI 题库管理**中选择“图片”“文档”或“章节”，查看和筛选题目，再点击“应用该题库”。应用后，儿童端后续答题会使用选中的题库。
4. 要添加其他教材，可点击“导入教材知识库”，选择年级、学科和册别，一次选择多个 UTF-8 编码的 `.md` 文件；确认章节名称和勾选项后保存。

例如，每个文件可以整理一个单元：

```text
六年级数学上册/
├─ 第一单元 分数乘法.md
├─ 第二单元 圆.md
└─ 第三单元 分数除法.md
```

软件会按已应用题库检查可用题目，在未做题不足时尝试后台补题。生成和补题需要可用网络、已配置的 API Key 和相应百炼额度；模型结果可能出错，仍需家长判断。

### 第三步：设置答题规则

- 在家长网页开启**整机管控**，调整每轮时长和每轮题数。
- 点击**立即弹题**可以手动发起答题；点击**家长放行**可以提前结束当前限制或刷题。
- 点击**开始刷题（50题）**可发起 50 题练习。当前实现中，一轮首次答对少于 45 题时会重新开始一轮；家长可提前放行。
- 在**定时任务**里选择“定时弹题”“定时刷题”或“暂停管控”，设置时间和重复日期。定时弹题可设置开始、结束时间与每轮题数；结束时间早于开始时间表示跨到次日。

### 家人协助与记录

家长可以生成、复制或撤销家人分享链接。分享页提供简化状态和快捷操作；家人分享页的放行次数目前按儿童手机本地日期限制为每天 3 次。分享链接包含访问凭据，应只发给信任的家人。

家长网页可查看题目出现、答对、答错和超时记录，以及系统记录的应用前台使用时长。使用时长是估算值，分屏、小窗、系统记录缺失等情况可能影响统计。

## 题库、教材和费用

- **章节题库**：按选择的教材章节生成和查看。
- **图片题库**：导入图片识别题目；可在图片题库中查看。
- **文档题库**：导入 `.doc` 或 `.docx` 文档；可在文档题库中查看。
- **教材知识库**：提供出题时参考的章节资料，不等同于已经生成的题目。导入教材后，还需要选择章节生成并应用题库。
- 图片、文档、教材内容或已有题目会在相应 AI 请求中发送给百炼处理。请自行管理 API Key；百炼调用按服务商规则计费，后台自动补题也可能产生费用。

## 权限与使用限制

普通 Android 权限不能保证防止卸载、强行停止、清除数据或撤销权限；设备管理应用和设置保护也有各自的系统限制。设备所有者属于另外的设备配置方式，具体能力取决于 Android 版本和厂商实现。后台服务、悬浮窗及辅助功能可能被系统限制，不同手机上的表现可能不同。

家长网页使用局域网 HTTP，配对和控制信息通过局域网传输。请只在可信家庭网络使用，不要直接暴露到互联网；不要将 API Key、家长密码或分享链接公开。

## 构建

需要 JDK 17–21、Android SDK Platform 34、Build Tools 34.0.0、Python 3 和 `zip`。脚本默认在 macOS 常见位置寻找 SDK 和 JDK；也可以设置 `WATCHGATE_ANDROID_SDK`、`WATCHGATE_JAVA_ROOT`。

```sh
# 构建儿童端；首次运行时生成本地签名密钥
bash build.sh

# 构建家长端，并将其加入儿童端的下载资源
bash parent-app/build.sh
bash build.sh

# 可选：构建儿童端、家长端、拍题应用和组合安装器
bash build-bundle.sh
```

默认输出到 `releases/`。`.signing/` 中的本地签名密钥是私密文件，请妥善备份并勿提交。不同签名构建的 APK 通常不能覆盖安装原有版本；卸载可能清除本机数据，请先做好备份。
