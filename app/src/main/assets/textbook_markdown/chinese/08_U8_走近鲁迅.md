# 第八单元｜初识鲁迅，感受鲁迅的魅力

-   教材页：109--125；PDF页：114--130
-   单元目标：借助相关资料理解课文；选取典型事例写一写好家风。

## 一、教材知识库

### 1. 鲁迅人物背景

鲁迅原名周树人，浙江绍兴人。主要作品包括小说集《呐喊》《彷徨》《故事新编》，散文诗集《野草》，散文集《朝花夕拾》和大量杂文。鲁迅是中国现代文学的重要作家、思想家和革命家。
学习本单元，要把课文中的人物形象与作品、时代背景和相关资料结合起来，不能只靠人物标签代替文本分析。

### 2.《少年闰土》

-   作者：鲁迅；出处：《故乡》节选；体裁：小说节选；教材页110--113。
-   主题：通过"我"与少年闰土的相识和交往，表现闰土见识丰富、聪明能干、活泼勇敢，也反映"我"对乡村生活和广阔世界的向往。

**内容结构** 1. 开头描写月下看瓜刺猹的少年形象。 2.
回忆"我"与闰土初次相识的背景。 3. 闰土介绍雪地捕鸟的方法。 4.
闰土介绍海边拾贝壳、看瓜刺猹等经历。 5. 闰土介绍潮汛时跳鱼儿等见闻。 6.
正月过去，闰土离开，两人分别。

**人物形象**
闰土勇敢、聪明、见识丰富、活泼、朴实。通过对话展示他的生活经验，通过"我"的反应侧面表现他的丰富见识。

**"我"的内心**
"我"对闰土好奇和欣赏；闰土的讲述拓展了"我"的见识；"高墙上的四角的天空"可理解为生活空间和见识受到局限的象征。

**表达方法**
开头环境和人物合写；外貌描写使人物具体；对话展示见识；第一人称"我"的反应侧面烘托闰土；闰土广阔的乡村生活与"我"有限的生活范围形成对比。

教材保留部分旧用字，如"带"在特定语境中对应现代规范写法"戴"，"希奇"对应"稀奇"。阅读时尊重原文，同时了解现代规范写法。

### 3.《好的故事》

-   作者：鲁迅；出处：《野草》；体裁：散文诗/象征性散文；教材页114--116。
-   主题：通过梦境般的江南水乡图景，表达对美好生活的憧憬，同时表现理想与昏沉现实之间的矛盾。

**内容结构** 1. 交代昏暗现实环境，作者闭眼休息。 2.
进入梦境，看到美丽、幽雅、有趣的故事。 3.
展开水乡倒影：树木、花草、村舍、人物和水中景物交织。 4.
梦境影像不断变化、融合和流动。 5.
作者正要凝视和追寻美好图景时，梦境突然破碎。 6.
作者醒来，只剩昏暗灯光，却仍记得曾见过美好的故事。

**深层理解** - 表层：梦境中的江南水乡图画。 -
深层：对美好生活、美好事物和理想世界的憧憬。 -
现实背景：昏沉现实与梦境明丽形成对照。 -
结尾：梦境消失，但追求美好没有消失。

**表达特点**
象征、意象组合、动态描写、色彩描写、虚实结合、现实与梦境对比。不能只按普通事件故事理解，要结合梦境画面和"昏沉的夜"理解象征意义。

### 4.《我的伯父鲁迅先生》

-   作者：周晔；体裁：回忆性叙事散文；教材页117--120。
-   主题：通过几件生活小事，表现鲁迅关心晚辈、爱护劳动人民、严肃认真、为别人着想的品质。

**主要事件** 1.
伯父去世后许多人前来吊唁，"我"疑惑伯父为什么受到那么多人的爱戴。 2.
伯父与"我"谈《水浒传》，用幽默方式提醒"我"读书不能囫囵吞枣。 3.
伯父谈"碰壁"，以含蓄方式表达对黑暗社会现实的批判。 4.
伯父和家人放花筒，表现慈祥、自然、愉快的一面。 5.
伯父帮助受伤的黄包车夫，体现对劳动人民的同情和关怀。 6.
女佣阿三讲述伯父病中仍关心别人，进一步表现他为别人着想。

**人物形象**
关心晚辈、幽默风趣、平易近人、同情劳动人民、忘我、严肃认真。

**结构和表达**
以"为什么受到这么多人的爱戴"为贯穿问题；用多个生活片段回答；通过语言、动作、对比和女佣的侧面叙述塑造人物；结尾总结品质，回应开头疑问。

### 5.《有的人------纪念鲁迅有感》

-   作者：臧克家；体裁：现代诗；教材页121--122。
-   主题：通过两种不同人生价值的对比，纪念鲁迅，赞美为人民服务的人，批判压迫人民、只为自己谋利的人。

**结构和手法** - 对比：贯穿全诗，呈现两种人生选择和不同历史评价。 -
反复：重复句式强化主题和节奏。 -
比喻、象征：用"牛马""野草"等形象表现不同人生价值。 -
借鲁迅纪念：突出鲁迅关心人民、为人民着想的精神。

**与《我的伯父鲁迅先生》联系**
前者通过生活事例呈现鲁迅的具体行为；后者从价值判断和历史评价角度概括两种人生。两篇共同表现鲁迅关心人民的精神。

### 6. 习作《传承好家风》

家风是家庭长期形成并传承的价值观念、行为习惯和待人处事方式。
写作步骤：确定家风主题→选择真实典型事例→写清人物做了什么和为什么→写出对自己的影响→说明自己如何继承。
常见问题：只讲道理没有事例；事例与主题不一致；只写长辈不写自己受到的影响；把家风写成口号。

### 7. 语文园地

-   鲁迅人物卡片：基本信息、代表作品、名言、典型事例、人物印象和资料来源。
-   标题作用：可能以人物、事件、物品命名，也可能设置悬念、概括中心或吸引读者；必须结合全文分析。
-   柳公权：唐代书法家。楷书用笔方圆并施，点画棱角分明，结构精妙，瘦硬挺拔。"颜筋柳骨"中的"柳骨"形容其骨力遒劲。
-   日积月累：鲁迅名句，涉及爱子之情、理想抱负、社会进步和民族精神。要结合语境理解。

## 二、标准题库

考查：鲁迅基本信息和作品；人物形象与典型事例；回忆性结构；象征、对比、反复和意象；现代诗主题；家风作文；标题作用；书法常识。
答题： - 人物：特点 + 具体事例 + 精神。 - 象征：具体形象 + 深层含义 +
与现实或主题联系。 - 对比：双方特点 + 对比效果 + 主题。 -
作文：家风主题明确 + 事例真实典型 + 写出影响和传承行动。
