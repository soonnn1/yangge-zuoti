# 第四单元｜小说阅读：情节、环境与人物形象

-   教材页：49--68；PDF页：54--73
-   单元目标：关注小说情节和环境，感受人物形象；发挥想象创编故事。

## 一、教材知识库

### 1. 小说阅读基础

小说基本要素： - 人物：故事中行动、选择和变化的人。 -
情节：事件发生、发展、转折和结局。 - 环境：自然环境和社会环境。 -
主题：作品通过人物和事件表达的思想或情感。

人物分析不能只贴形容词，要结合行为、语言、心理、关键选择、他人评价和环境处境。
答题结构：人物特点 + 具体情节或描写依据 + 体现的性格品质。

环境描写作用：交代时间地点天气；渲染气氛；推动情节；暗示处境；烘托心理；与人物行为形成对照。

### 2.《桥》

-   作者：谈歌；体裁：小说；教材页50--52。
-   主题：洪水来临时，老支书组织村民有序过桥，最后为救年轻人而牺牲，表现党员干部的责任担当和无私精神。

**情节结构** 1. 洪水突然来临，村民惊慌寻找出路。 2.
唯一通道是一座窄木桥，老支书站在桥前指挥。 3.
老支书要求群众排队，党员排在后面。 4.
他把违反秩序的年轻人从队伍中揪出，让其排到后面。 5.
洪水上涨，老支书和年轻人留在最后。 6.
老支书把年轻人推上桥，桥塌后两人被洪水吞没。 7.
结尾揭示老支书与年轻人的父子关系。

**人物形象**
老支书临危不乱、公正严格、以身作则、大公无私，也有深沉父爱。年轻人从起初不服从，到最后试图让父亲先走，表现关系变化。

**环境和结构**
暴雨、洪水和木桥不断变化，推动情节升级；短句使节奏紧张；结尾才揭示父子关系，形成转折，改变读者对前面情节的理解。"桥"既是逃生通道，也可象征责任、生命和希望。

### 3.《穷人》

-   作者：列夫·托尔斯泰；译者：草婴；体裁：小说；教材页53--57。
-   主题：渔夫和桑娜生活贫困，却主动收养邻居西蒙的两个孩子，表现普通劳动者的善良、同情和担当。

**情节结构** 1. 桑娜在家照顾孩子，丈夫冒风暴出海。 2.
桑娜担心丈夫，去探望生病的邻居西蒙。 3.
桑娜发现西蒙已经去世，两个孩子无人照顾。 4.
她把孩子抱回家，内心忐忑，担心丈夫无法接受。 5.
渔夫回家，桑娜犹豫着说明邻居去世。 6.
渔夫主动提出把孩子抱来，桑娜告诉他孩子已经在家。

**人物形象** -
桑娜：善良、有同情心、勤劳顾家；内心既担心家庭负担，又无法放弃孩子。 -
渔夫：勤劳、能吃苦、善良、有责任感；明知生活困难仍愿意承担。

**描写分析**
桑娜抱回孩子后的内心独白表现矛盾；屋外风暴和寒冷交代生活艰难；渔家小屋温暖整洁，衬托桑娜勤劳；西蒙家潮湿阴冷，与渔家形成对比，突出孩子处境。
结尾揭示孩子已被抱回，既形成悬念，也说明夫妻二人心意相通。

### 4.《金色的鱼钩》

-   作者：杨旭；体裁：小说；教材页58--62。
-   主题：老班长接受任务照顾生病战士，自己忍饥挨饿，最终牺牲，表现忠于革命、关爱战友和高度责任感。

**情节结构** 1. 长征途中三名病号掉队，老班长受命照顾。 2.
粮食耗尽，老班长想办法找食物。 3. 他用缝衣针制作鱼钩，钓鱼煮汤给病号吃。
4. "我"发现老班长实际吃草根和鱼骨，理解他把食物留给战友。 5.
老班长要求病号坚持吃饭、继续前进，并严格要求"我"服从分工。 6.
病号接近草地边缘，老班长因长期饥饿和劳累倒下。 7.
老班长牺牲，"我"保存鱼钩作为纪念。

**人物形象** 忠于任务、关心战友、坚强克己、有组织纪律、责任心强。

**叙述和象征**
第一人称通过"我"的观察和心理变化，让读者逐渐发现老班长的秘密。"金色的鱼钩"由普通工具变成牺牲精神的见证；"金色"象征精神价值。

### 5. 口语交际《请你支持我》

说服步骤：礼貌说明来意→清楚表达想法→解释目的和意义→预测对方担心→提出具体理由或方案→听取意见并调整。
错误：只说"我想做"不讲理由；只考虑自己；语气强硬；面对反对意见只争辩不回应顾虑。

### 6. 习作《笔尖流出的故事》

小说创编要素：环境、人物、情节、心理。
构思：确定主要人物和中心事件→设计关系和矛盾→选择环境→安排起因、发展、转折、结局→通过语言、动作、神态、心理和环境表现人物。
重点：故事围绕主要人物展开，情节完整，环境和心理描写服务于故事。

### 7. 快乐读书吧《笑与泪，经历与成长》

《童年》作者高尔基，主人公阿廖沙。父亲去世后随母亲生活，经历家庭矛盾和艰难；外祖母及其他善良人物给他温暖和支持。
阅读长篇小说：弄清主人公和人物关系；记录重要事件和人物变化；关注人物在不同环境中的选择；不要只记情节，还要看经历如何影响成长。

### 8. 语文园地

-   感受人物：关注情节、语言、动作、心理和环境；想象自己处于人物位置，但分析仍需依据文本。
-   环境衬托人物：《穷人》中恶劣天气与温暖整洁的小屋形成对照，写生活条件，也衬托桑娜的勤劳和善良。
-   日积月累《送元二使安西》：王维，唐代。

原文： \> 渭城朝雨浥轻尘，客舍青青柳色新。\
\> 劝君更尽一杯酒，西出阳关无故人。

诗意：清晨细雨润湿尘土，客舍和柳色清新；诗人劝友人再饮一杯，表达送别时的依依不舍和对友人的关切。

## 二、标准题库

考查：小说三要素、情节概括、人物形象、语言动作心理描写、环境作用、悬念转折、象征、说服表达和小说创编。
答题： - 人物：特点 + 具体行为/语言 + 品质。 - 环境：环境特点 +
渲染气氛/交代背景/推动情节/衬托人物 + 主题联系。 - 标题：表层含义 +
深层象征 + 与人物或主题联系。
