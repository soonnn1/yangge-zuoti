# 第五单元｜围绕中心意思写

-   教材页：69--80；PDF页：74--85
-   单元目标：理解中心意思与材料选择的关系；重要部分写得详细、具体。

## 一、教材知识库

### 1. 中心意思与材料

中心意思是文章主要想表达的思想、情感或观点。它决定选择什么材料、如何安排顺序、哪些内容需要重点描写。

-   选材：选择能够表达中心的事例。
-   取舍：与中心关系不大的材料应删减或简写。
-   详略：最能突出中心的材料详写，辅助材料略写。
-   顺序：根据表达需要安排材料先后。
-   照应：结尾可回扣中心，使文章完整。

写作流程：明确中心→列材料→判断相关性→选典型材料→确定详略→补充细节→检查各段是否服务中心。

### 2.《灯光》

-   作者：王愿坚；体裁：记叙文；教材页70--72。
-   主题：通过郝副营长在战斗中为后续部队照明而牺牲的故事，表达对革命先烈的怀念，说明今天幸福生活来之不易。

**内容结构** 1. 由天安门广场的灯光引出回忆。 2.
回忆战斗前，郝副营长借微弱火光阅读，看到孩子在电灯下学习的插图。 3.
他表达对未来的向往，希望孩子们能在明亮灯光下读书。 4.
战斗中，后续部队因黑暗无法找到突破口。 5.
郝副营长点燃书本，为部队照亮道路，自己因此暴露并牺牲。 6.
回到现实，作者再次看到天安门灯光，想起这位年轻战友。

**三种灯光的联系** - 插图中的灯光：代表对和平生活和孩子学习的憧憬。 -
战场上的微弱火光：代表为理想和任务作出的牺牲。 -
天安门广场的璀璨灯光：代表理想实现后的幸福生活，也寄托对先烈的怀念。

**表达方法**
现实引出回忆再回到现实；灯光作为线索贯穿全文；首尾照应；过去牺牲与今天幸福形成对照；灯光象征希望、理想和光明生活。

### 3.《盼》

-   作者：铁凝；体裁：记叙文；教材页73--75。
-   主题：围绕"盼"字，写"我"得到新雨衣后急切盼望下雨的心理和行动，表现儿童天真细腻的心理。

**内容结构** 1. 得到新雨衣：写雨衣外形和试穿时的兴奋。 2.
盼望变天：天气持续晴朗，雨衣没有机会穿。 3.
发现要下雨：风起、云来、雨点落下，"我"兴奋地回家。 4.
想办法穿雨衣：借买酱油等理由试图出门，却被妈妈识破或阻止。 5.
雨停后的等待：看到雨后景象，想象雨点落在雨衣上的样子。 6.
第二天终于下雨：穿上新雨衣，在雨中体验期待已久的快乐。

**心理变化**
得到雨衣时兴奋；长期晴天时失望焦急；看到云和雨点时惊喜；妈妈不让出去时着急；雨停时担心机会消失；第二天穿上雨衣时满足快乐。

**表达方法**
心理描写、动作描写、语言描写、环境描写、拟人和细节描写。反复写天气、雨点和雨衣，是为了突出"盼"的中心。文章重点不在最后穿上雨衣，而在等待、寻找机会、失望和希望反复变化的过程。

### 4. 习作《围绕中心意思写》

步骤： 1. 选择一个汉字或中心词，如"甜、忙、暖、悔、盼"。 2.
明确中心含义。 3. 列出生活中能表现中心的材料。 4.
选择最典型、最有表现力的材料。 5. 安排材料顺序。 6.
确定重点段落并写清具体过程。 7. 检查材料是否都围绕中心。

判断材料不是看它是否有趣，而是看它是否能帮助表达中心。

### 5. 例文学习

**《爸爸的计划》** - 中心：表现爸爸爱订计划、执行计划一丝不苟。 -
结构：先总写爸爸给家人订计划，再用执行家务计划、安排暑假计划等事例具体表现。 -
写法：概括人物特点，再用典型事例支撑。

**《小站》** -
中心：小站虽简朴偏僻，却因工作人员精心布置和维护而给旅客带来温暖。 -
结构：先写小站小、位置偏、设施简单，再写工作人员布置的环境和喷水池、杏花等细节，最后点出小站带来的春意。 -
写法：先抑后扬、环境对比、细节描写、借景表达中心。 -
学习重点："小"与最后呈现的温暖形成反差，突出工作人员的用心。

### 6. 语文园地

-   材料选择：中心确定后，选择最能说明中心的事例。
-   重点写具体：补充环境、动作顺序、语言、神态、心理和事情影响。
-   列提纲：中心、主要材料、材料顺序、详写略写、结尾回扣。

## 二、标准题库

考查：中心意思概括、材料与中心关系、选材取舍、详略安排、线索照应象征、心理动作语言环境描写、作文提纲。
常见题型：判断材料是否适合；概括中心；说明某事例为什么详写；分析标题和中心；给作文列提纲；修改材料堆砌的作文。
答题： - 材料题：材料内容 + 与中心的关系 + 是否突出中心。 -
详略题：指出重点 + 说明最能表现中心 + 细节效果。 - 中心题：对象 +
主要内容 + 作者思想或情感。
