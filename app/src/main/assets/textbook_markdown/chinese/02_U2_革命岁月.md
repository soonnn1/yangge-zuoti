# 第二单元｜重温革命岁月

-   教材页：13--30；PDF页：18--35
-   单元目标：体会革命前辈为理想奋斗的精神；理解点面结合的场面描写，并尝试运用。

## 一、教材知识库

### 1. 核心知识：点面结合

-   **面**：整体场景、群体状态、整体气氛。
-   **点**：个别人物、典型动作、语言、神态或具体细节。
-   **点面结合**：既写整体规模和气势，又选取个体细节让场面具体可感。
-   常见效果：避免只有宏观概括、没有细节；也避免只有个别人物、缺乏整体氛围。

### 2.《七律·长征》

-   作者：毛泽东；体裁：七言律诗；教材页14--15。
-   背景：红军长征。
-   主旨：表现红军面对长征艰难险阻时的革命乐观主义精神和坚定信念。

**体裁知识**
七律是七言律诗的简称，通常八句，每句七字；中间两联讲究对仗。诗歌以凝练语言和典型意象表现宏大的历史经历。

**内容结构** - 首联：总写长征艰难，但红军把困难看作平常。 -
颔联：写五岭、乌蒙山，突出山势险峻，又以夸张和比喻表现红军无畏。 -
颈联：写金沙江、大渡河，表现渡河作战的艰险和战胜困难的勇气。 -
尾联：写翻越岷山后的喜悦，突出胜利信心。

**重点意象**
五岭、乌蒙代表连绵险峻的山脉；金沙江、大渡河代表长征中的水上关隘；岷山积雪表现自然环境严酷，也成为胜利前景的象征。"细浪""泥丸"等意象通过夸张和比喻减弱山势的压迫感，突出红军藐视困难的气魄。

**情感理解**
诗歌不是否认长征艰难，而是表现坚定理想、勇气和集体力量能够帮助红军克服困难。

### 3.《狼牙山五壮士》

-   作者：沈重；体裁：记叙文；教材页16--18。
-   主题：五位战士为掩护群众和主力部队转移，英勇战斗并完成任务，表现英勇顽强、宁死不屈的精神。

**事件结构** 1. 接受任务：六班五位战士承担掩护群众和连队转移的任务。 2.
引敌上山：利用地形阻击敌人，把敌人引向狼牙山。 3.
选择道路：班长决定把敌人引向险要山顶，避免暴露群众和主力部队。 4.
顶峰战斗：依托地形继续战斗，弹药用尽后用石块打击敌人。 5.
英勇跳崖：完成任务后，以壮烈行动表现不屈精神。

**人物形象** - 马宝玉：沉着、果断、坚定，关键时刻作出决策并带头行动。 -
葛振林：战斗勇猛，表现强烈战斗意志。 - 宋学义：动作有力，体现果敢。 -
胡德林、胡福才：年轻但专注、勇敢，坚决执行任务。 -
五人整体：目标一致、相互配合、服从命令、勇于牺牲。

**点面结合**
第二自然段先写五位战士共同战斗的整体场面，再分别写班长指挥、副班长射击、战士投弹和瞄准等个体表现。"面"呈现群体战斗状态，"点"突出个人动作和性格；效果是群体形象和个体形象都鲜明。

**动作描写分析**
分析英雄气概时不能只写"他们很勇敢"，要结合关键选择、战斗动作、任务意识和集体利益说明。

### 4.《开国大典》

-   体裁：记叙文、重大历史场面报道式叙事；教材页19--23。
-   主题：记录中华人民共和国成立时开国大典的盛况，表现全国人民的自豪、激动和对新中国的热爱。

**内容顺序** 1. 交代时间、地点、参加人员和会场布置。 2.
群众入场：不同地区、不同职业的群众汇集广场。 3.
典礼开始：宣布中央人民政府成立。 4.
升旗与宣读公告：升国旗、奏国歌、宣读政府公告。 5.
阅兵式：受阅部队依次经过主席台。 6.
群众游行：夜间灯火、礼花和游行队伍形成热烈场面。

**场面描写** - 会场布置：空间方位和建筑细节交代会场。 -
群众入场：整体数量和群体动作呈现人潮。 -
典礼仪式：宣告、掌声、国旗和礼炮表现庄严。 -
阅兵式：先写整体行进，再写海军、步兵、炮兵、战车、骑兵和空军的特点。 -
群众反应：欢呼、鼓掌、挥动物品等细节表现情绪。

**点面结合**
阅兵式先写受阅部队整体整齐行进，再具体写不同军种的服装、队形、装备和动作。整体规模是"面"，各方阵特点是"点"，使场面既宏大又具体。

**表达效果**
时间顺序完整；空间描写帮助理解会场布局；反复写掌声、欢呼突出情绪高涨；数字和典型细节增强真实感；庄严仪式与热烈情绪共同表现历史意义。

### 5.《我的战友邱少云》

-   作者：李元兴；体裁：记叙文；教材页24--26。
-   主题：通过潜伏任务中的经历，表现邱少云为了集体任务严守纪律、顾全大局的精神。

**事件结构** 1. 潜伏准备：交代山沟环境、敌我距离和伪装条件。 2.
潜伏等待：环境危险，任何细微动作都可能暴露部队。 3.
意外发生：敌方火力引发草木起火，火势接近潜伏位置。 4.
战友遇险：邱少云为了不暴露潜伏部队，坚持不动。 5.
任务完成：部队按计划发起攻击，战友以战斗行动表达怀念。

**叙述与描写** - 第一人称"我"使读者从战友视角体验紧张和担忧。 -
"我"的心理活动表现环境危险，也衬托邱少云的纪律性和意志。 -
潜伏地点靠近敌方阵地，环境越危险，人物坚守纪律的行为越突出。 -
环境与人物行为形成对照，强化人物形象。

### 6. 口语交际《演讲》

演讲目的：发表见解、阐明事理或抒发情感，使听众理解、认同并产生共鸣。

演讲稿结构： 1. 开头：明确主题，吸引听众。 2.
主体：提出鲜明观点，选择典型事例、事实或名言说明。 3.
结尾：总结观点、发出倡议或表达愿望。

表达要求：观点鲜明；材料真实典型；语言有感染力；语气自然；适当停顿、重复或配合动作；姿态大方。

### 7. 习作《多彩的活动》

写一次活动，交代时间、地点、参与者和活动过程；选择印象最深的部分详细写；场面描写兼顾整体和个体；描写同学的动作、语言、神态；结尾写收获、感受或意义。

### 8. 语文园地

-   时间轴：按历史事件发生顺序理解革命题材作品，区分故事发生年代与作品出版年代。
-   分号：用于复句内部并列分句之间，停顿比逗号大、比句号小；分句通常相对完整。
-   日积月累：四则爱国主题名句，涉及仁义、为国献身、守土责任和忧国情怀。学习时理解关键词和价值观，不只背字面。

## 二、标准题库

考查：七律体裁特点、诗歌情感、事件顺序、人物动作语言神态心理、点面结合、场面描写、环境描写作用、演讲稿、活动习作和分号。
常见题型：按顺序概括事件；结合行为分析人物；指出段落中的点和面；分析环境描写；概括开国大典场面；设计演讲提纲；修改活动作文；判断分号用法。
答题要点： - 人物题：特点 + 行为依据 + 精神品质。 - 场面题：整体描写 +
个体细节 + 表达效果。 - 环境题：环境特点 + 对情节的作用 +
对人物的衬托。 - 诗歌题：关键词 + 画面 + 情感。
