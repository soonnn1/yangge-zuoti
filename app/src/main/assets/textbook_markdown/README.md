# 六年级数学上册标准化 Markdown 知识库 V2

## 文件结构
- `00_总索引_按单元读取.md`：总目录和按单元读取规则。
- `01_U1_...md` 至 `08_U8_...md`：8个正式单元独立知识库。
- `09_千问调用模板.md`：软件向千问发送任务时使用的提示词模板。
- `10_知识点ID总索引.md`：全册知识点编号查询。

## 内容说明
每个单元文件都包含：
- 教材知识总结；
- 知识点详细讲解；
- 概念、意义、公式、推导和计算步骤；
- 教材典型情境和数量关系；
- 考查范围和命题方式；
- 答案与解析要求；
- 常见错误、掌握等级和补救建议；
- 对应教材页的纯文本提取。

## 使用方式
1. 软件导入整个文件夹。
2. 启动时读取总索引。
3. 用户选择章节后，只读取对应单元 Markdown。
4. 按任务需要把当前学生的相关学习记录传给模型。
5. 千问输出题目草稿，软件校验后保存；正式题库需审核。

## 重要边界
- 这是纯 Markdown 知识库，不包含教材图片。
- PDF文本提取可能无法完整表达图形、统计图、表格布局和空间关系。
- 对图形依赖题，缺少足够文字条件时不出题，不猜图。
- 学生真实学习记录是动态数据，应该保存在软件数据库，不应写进静态教材知识库。
- 教材中出现的历史数据不代表当前实时数据。
