# Unit 2 — Let’s travel!

- 教材印刷页码：9–16
- PDF 页码：18–25
- 单元目标：说出国家名称；谈论旅行经历；介绍感兴趣的地方。

## 一、教材知识库

### 1. 单元主题与语义范围
本单元围绕国家、城市、旅游景点和旅行经历展开，要求学生能够：
- 识别国家名称及其代表性地点；
- 介绍某个地方的特色；
- 谈论旅行中做过的事情；
- 描述旅行经历和感受；
- 讨论旅行前需要做的准备；
- 写简短的旅行明信片或旅行记录。

- leaf / leaves：叶子；

国家名称前是否使用 the 要按专有名词固定形式记忆，例如 the UK、the USA；China、Australia、Singapore 等不加 the。

#### 2.2 景点与旅游活动
教材涉及的地点和活动包括：
- Big Ben；

学习要求：

- 能理解景点名称是专有名词，书写时注意首字母大写；
- 能使用动词描述旅行活动；

#### 2.3 描述地方特色
教材出现的常用表达：

- in the sea：在海里；

### 3. 旅行经历表达
本单元通过旅行日志、博客和明信片表达过去的旅行经历。
常见信息维度：
- 去了哪里；
- 什么时候去；
- 做了什么；
- 看到了什么；
- 吃了什么；
- 感受如何；
- 与谁一起旅行。

### 4. 重要句型与交际功能

#### 4.1 介绍国家或地方
- This country is famous for ...
- There are ... in this country.
- You can see ...
- It is a wonderful place to ...
- I come from ...
- I live in ...

功能：介绍国家、城市、家乡及其特色。

#### 4.2 谈论旅行经历
- Where did you go?
- What did you do?
- What did you see?
- How was your holiday?
- I went to ...
- I visited ...
- I saw ...
- I had a great time.

功能：询问和描述过去的旅行经历。

#### 4.3 表达旅行计划与准备
教材涉及的准备事项：
- book train tickets；
- check the weather；
- get things ready；
- make a travel plan；
- decide where to go；

常用表达：
- We will go to ...
- Can you help me ...?
- Let’s ... together.
- What do we need to do?
- We also need to think about ...

### 5. 语法与语言规律

#### 5.1 一般过去时：描述已经发生的旅行活动
结构：
- 肯定句：主语 + 动词过去式 + 其他；
- 否定句：主语 + didn’t + 动词原形 + 其他；
- 一般疑问句：Did + 主语 + 动词原形 ...?
- 特殊疑问句：疑问词 + did + 主语 + 动词原形 ...?

重点：
- did / didn’t 后面的行为动词必须使用原形；
- 肯定句中的行为动词使用过去式；
- 过去时间标志可帮助判断时态，如 yesterday、last holiday、last summer 等；
- 不规则动词过去式需要单独记忆。

#### 5.2 本单元常见不规则动词
教材旅行语境中涉及的常见变化：
- go → went；
- see → saw；
- take → took；
- swim → swam；
- have → had；
- buy → bought；
- eat → ate；
- get → got；
- do → did；
- visit 为规则变化：visit → visited；
- play 为规则变化：play → played；
- watch 为规则变化：watch → watched。

说明：不规则动词不能简单通过加 -ed 构成过去式。

#### 5.3 一般过去时与一般现在时的区别
- 一般现在时：表达现在的事实、习惯或普遍情况；
- 一般过去时：表达过去某个时间已经发生的动作或状态。
判断时应结合句子时间、上下文和动词形式，不应只依靠单个时间词。

#### 5.4 一般将来表达
教材旅行准备部分出现 will 表达将来的行动或安排。
结构：主语 + will + 动词原形。
否定：主语 + will not / won’t + 动词原形。
疑问：Will + 主语 + 动词原形 ...?

重点：
- will 后接动词原形；
- will 不随主语人称变化；
- 用于谈论将来要做的事情或计划。

### 6. 明信片与旅行短文
明信片常见结构：
1. 称呼：Dear ...,
2. 说明所在地点；
3. 介绍参观或体验的活动；
4. 描述景色、食物或感受；
5. 结束语：Love, / Best, 等；
6. 写信人姓名。

写作要求：
- 内容围绕旅行经历；
- 过去发生的事情使用一般过去时；
- 地点、景点和国家名称首字母大写；
- 句子之间保持时间或活动顺序；
- 不能把一般现在时和一般过去时随意混用。

### 7. 阅读与语篇知识
本单元阅读材料包括家乡介绍、旅游行程、博客、明信片和旅行准备清单。
阅读时重点提取：
- 人物来自哪里或住在哪里；
- 地点所属国家；
- 地方的特色；
- 旅行日期或行程顺序；
- 做过的活动；
- 人物的感受；
- 旅行前的准备事项。

### 8. 本单元重点与易错点
- 国家名称与景点名称属于专有名词，注意首字母大写。
- the UK、the USA 等固定名称中的 the 不可随意省略。
- did / didn’t 后必须使用动词原形。
- 肯定句中要使用正确的过去式，尤其是不规则动词。
- will 后使用动词原形，不能再加过去式或第三人称单数词尾。
- visit 与 go 的用法不同：visit 后直接接地点；go 表示“去”，常与 to 连用。
- 地点介词短语要结合固定搭配记忆。
- 明信片描述已发生的旅行经历，主体时态通常为一般过去时。

## 二、标准题库

### 1. 考查范围
- 国家、城市、景点和旅游活动词汇；
- 国家与景点匹配；
- 描述地方特色的短语；
- 一般过去时肯定、否定和疑问结构；
- 规则与不规则动词过去式；
- will 表示将来；
- 旅行准备表达；
- 明信片结构与旅行短文阅读。

### 2. 推荐题型与命题规则
- **国家与景点匹配**：考查国家、城市、著名景点之间的对应关系。
- **词汇辨析**：考查 travel、visit、go、see、take、learn 等动词的意义和搭配。
- **动词变形题**：给出动词原形，要求填写过去式；覆盖规则和不规则变化。
- **时态选择题**：根据时间背景判断一般现在时、一般过去时或 will 结构。
- **句型转换题**：一般过去时肯定句转换为否定句、一般疑问句或特殊疑问句。
- **语篇排序题**：根据旅行时间顺序排列活动。
- **阅读理解题**：提取地点、活动、时间、感受等信息。
- **明信片写作题**：按称呼、旅行内容、感受和署名组织文本。

### 3. 答案判定标准
- 专有名词拼写正确，大小写符合规范。
- 一般过去时肯定句使用正确过去式。
- did / didn’t 后使用动词原形。
- will 后使用动词原形。
- 阅读题答案必须与材料信息一致。
- 写作应包含基本旅行信息，时态前后一致，语句有合理顺序。
