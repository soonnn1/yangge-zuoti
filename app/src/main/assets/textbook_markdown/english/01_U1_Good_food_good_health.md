# Unit 1 — Good food, good health

- 教材印刷页码：1–8
- PDF 页码：10–17
- 单元目标：说出健康与不健康食物；谈论食物和健康；表达健康饮食建议。

## 一、教材知识库

### 1. 单元主题与语义范围
本单元围绕饮食与健康展开，要求学生能够：
- 识别常见食物和饮料名称；
- 区分健康与不健康的饮食选择；
- 谈论食物、饮料及其营养或能量信息；
- 描述日常饮食习惯；
- 对不健康饮食提出建议；
- 在餐馆点餐或表达食物、饮料需求。

### 2. 核心词汇

#### 2.1 食物与饮料
教材涉及的食物、饮料词汇包括：
- 水果：apple, banana, orange, tomato, grapes, blueberries 等；
- 蔬菜：carrot, potato 及其他常见蔬菜；
- 主食：rice, noodles, bread；
- 肉类及蛋类：fish, meat, eggs, chicken, duck；
- 乳制品：milk, yoghurt；
- 其他食物：hamburger, chocolate, ice cream, hot dog；
- 饮料：water, juice, cola。

学习要求：
- 能识别词义并正确归类；
- 能区分可直接食用的食物名称与饮料名称；
- 能在谈论饮食时使用恰当的名词；
- 注意单词拼写，尤其是容易混淆的字母组合和复数形式。

#### 2.2 健康与饮食评价
- healthy：健康的；
- unhealthy：不健康的；
- fat：脂肪；fat 在描述食物时可表示脂肪含量高；
- sugar：糖；
- salt：盐；
- energy：能量；
- kcal：千卡，食物能量单位。

理解要求：
- healthy / unhealthy 表示对饮食或生活方式的健康评价；
- high in sugar 表示含糖量高；
- high in fat 表示脂肪含量高；
- 食物能量数值与糖、脂肪等营养信息不是同一个概念，不能混为一谈。

### 3. 食物分类与健康饮食知识
教材通过食物金字塔表达均衡饮食观念。主要信息如下：
- 谷物类主食提供日常活动所需能量；
- 水果和蔬菜是均衡饮食的重要组成部分；
- 鱼、肉、蛋等食物提供身体所需营养；
- 牛奶和酸奶等乳制品属于饮食组成部分；
- 高脂肪、高盐、高糖食物不宜过量；
- 饮水是健康生活的重要部分；
- 健康饮食强调食物种类多样、搭配合理，而不是只吃某一种食物。

教材强调的判断原则：
- 不应把某一种食物简单认定为任何情况下都绝对有益或有害；
- 应关注摄入量、食物类别和饮食搭配；
- 水果和蔬菜应成为日常饮食的重要组成；
- 不宜过量摄入脂肪、盐和糖。

### 4. 重要句型与交际功能

#### 4.1 表达食物喜好
- What food do you like?
- What’s your favourite food?
- My favourite food is ...
- I like ... / I don’t like ...

功能：询问和表达食物喜好。

#### 4.2 询问饮食习惯
- Do you eat ... every day?
- What do you eat / drink?
- How much ... do you eat / drink?

功能：了解某人的饮食习惯。回答时要注意问句中的助动词和主语。

#### 4.3 询问健康状况
- What’s the matter?
- I don’t feel well.
- My stomach hurts.

功能：询问身体状况、描述不适。描述身体感受时，注意主语与动词形式的搭配。

#### 4.4 提出建议
- You should ...
- Please don’t eat / drink ...
- Eat / Drink more ...

功能：
- should 用于提出建议，后接动词原形；
- don’t 后接动词原形，用于提出否定建议或提醒；
- more 表示“更多”，可修饰可数或不可数名词，具体形式取决于名词。

#### 4.5 餐馆点餐
教材提供的常用表达：
- What would you like to have today?
- Anything to drink?
- Would you like ...?
- Your food will be ready in ... minutes.
- How about ...?
- I’ll have ... / I’d like to have ...

功能：询问顾客需求、提出选择、表达点餐内容和等待时间。

### 5. 语法与语言规律

#### 5.1 一般现在时：描述习惯和事实
本单元大量使用一般现在时谈论饮食习惯、喜好和健康事实。
- 肯定句：主语 + 动词原形；第三人称单数主语后，行为动词通常加 -s 或 -es。
- 否定句：主语 + don’t / doesn’t + 动词原形。
- 一般疑问句：Do / Does + 主语 + 动词原形 ...?
- 特殊疑问句：疑问词 + do / does + 主语 + 动词原形 ...?

关键点：
- he / she / it 等第三人称单数作主语时，肯定句中的行为动词要注意形式变化；
- does / doesn’t 已经体现第三人称单数，后面的行为动词必须用原形；
- 描述经常发生、长期保持的习惯，通常使用一般现在时。

#### 5.2 should 提建议
结构：主语 + should + 动词原形。
否定结构：主语 + shouldn’t + 动词原形。
疑问结构：Should + 主语 + 动词原形 ...?

关键点：
- should 是情态动词；
- should 后面必须接动词原形；
- 不随主语人称变化；
- 表示建议，不表示已经发生的事实。

#### 5.3 祈使句
用于提出要求、建议或提醒。
- 肯定祈使句：动词原形开头；
- 否定祈使句：Don’t + 动词原形；
- 礼貌表达可在句首或句中加入 please。

关键点：祈使句通常省略主语 you，谓语动词使用原形。

#### 5.4 可数名词与不可数名词
食物词汇中既有可数名词，也有不可数名词。
- 可数名词有单数和复数形式；
- 不可数名词通常没有复数形式；
- some / any、数量表达与名词类型有关；
- 不要仅凭中文词义判断英语名词是否可数，应结合教材词汇和实际用法记忆。

### 6. 阅读与语篇知识
本单元阅读材料涉及：
- 食物信息及能量标识；
- 对健康饮食的介绍；
- 不良饮食习惯及其影响；
- 医生与病人的简短对话；
- 健康饮食建议。

阅读理解应关注：
- 文章或对话的主题；
- 人物的饮食习惯；
- 食物与健康之间的关系；
- 具体信息与原因；
- 建议内容及其针对的问题。

### 7. 本单元重点与易错点
- healthy 与 unhealthy 的含义相反，拼写不可混淆。
- high in sugar / high in fat 表示某种成分含量高，不等于食物能量数值。
- should 后必须使用动词原形，不能使用第三人称单数形式或动词过去式。
- don’t / doesn’t 后必须使用动词原形。
- 第三人称单数的一般现在时肯定句要注意动词变化。
- What’s the matter? 用于询问身体或事情出了什么问题；回答应描述具体情况。
- 表达建议时，应让建议与问题对应，不能只堆砌 should 句型。
- 点餐表达中，I’d like ... 和 I’ll have ... 都可用于表达需求，但要结合交际情境理解。

## 二、标准题库

### 1. 考查范围
- 食物、饮料及健康相关词汇；
- 食物分类和健康饮食观念；
- 一般现在时描述习惯；
- do / does 引导的一般疑问句；
- 第三人称单数动词形式；
- should / shouldn’t 提建议；
- 祈使句；
- 身体不适表达；
- 点餐交际表达；
- 健康主题阅读理解。

### 2. 推荐题型与命题规则
- **词汇分类题**：按水果、蔬菜、主食、肉类、饮料等分类；答案必须符合词义。
- **词义匹配题**：考查 healthy、unhealthy、sugar、fat、energy 等词义。
- **单词拼写题**：根据中文或语境填写单词；不得用教材未出现且超出教学范围的词替代目标词。
- **语法选择题**：重点考查 do / does、don’t / doesn’t、第三人称单数动词变化。
- **句型转换题**：一般现在时肯定句、否定句和一般疑问句之间转换。
- **建议表达题**：根据饮食问题选择或写出 should / shouldn’t 句子。
- **情境对话题**：健康咨询或餐馆点餐；判断表达是否符合交际目的。
- **阅读理解题**：从饮食习惯、食物信息和健康建议中提取事实、原因和结论。

### 3. 答案判定标准
- 词汇题：拼写正确、词义匹配、词形符合句子要求。
- 语法题：助动词、主语、谓语形式一致；should 后使用动词原形。
- 句型题：保留原句核心意思，语序和标点符合英语表达。
- 建议题：建议内容与问题相关，结构正确。
- 阅读题：答案必须能从材料中找到依据，不得仅凭常识猜测。

### 2. 错误类型记录
- 词汇混淆：食物类别、健康评价词、营养成分词混淆。
- 拼写错误：单词字母遗漏、顺序错误、复数形式错误。
- 动词形式错误：第三人称单数漏加 -s / -es。
- 助动词错误：does / doesn’t 后误用动词第三人称单数。
- 情态动词错误：should 后误用 to do、doing 或过去式。
- 句型错误：一般疑问句语序不正确。
- 语用错误：建议与问题不匹配，点餐表达不符合场景。
- 阅读错误：忽略题干关键词，混淆事实与建议。

### 3. 下一步训练建议
- 词汇错误：先按食物类别复习，再做拼写和词义辨析。
- 动词形式错误：集中练习一般现在时第三人称单数及 do / does 句型。
- should 错误：练习“问题—建议”对应关系。
- 阅读错误：训练定位人物习惯、食物信息、原因和建议。
- 交际错误：练习健康咨询和点餐的完整对话。
