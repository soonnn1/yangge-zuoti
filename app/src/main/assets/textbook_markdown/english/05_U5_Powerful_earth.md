# Unit 5 — Powerful earth

- 教材印刷页码：33–40
- PDF 页码：42–49
- 单元目标：说出自然灾害名称；谈论自然灾害中的应对方式；分享灾害中人们互相帮助的故事。

## 一、教材知识库

### 1. 单元主题与语义范围
本单元围绕自然灾害及其应对展开，要求学生能够：
- 识别常见自然灾害；
- 描述灾害发生时的天气、环境和现场情况；
- 理解灾害可能造成的影响；
- 谈论灾害发生时应做和不应做的事情；
- 阅读并讲述灾害中的互助故事；
- 表达帮助他人和遵守安全要求的意识。

### 3. 自然灾害类型与特征
教材主要涉及四种自然灾害：

#### 3.1 Flood
洪水。教材描述的典型情况：
- 连续降雨；
- 街道或地面被水淹没；
- 水位上升可能影响房屋和道路；
- 人员需要远离危险区域并听从安全安排。

#### 3.2 Snowstorm
暴风雪。教材描述的典型情况：
- 大量降雪；
- 天气寒冷；
- 风力较强；
- 道路积雪，车辆可能无法正常通行；
- 人们可能需要互相帮助。

#### 3.3 Tsunami
海啸。教材描述的典型情况：
- 海水形成巨大波浪；
- 海水可能冲向海岸并淹没沿海区域；
- 海边人员需要及时远离危险区域。

#### 3.4 Earthquake
地震。教材描述的典型情况：
- 地面发生震动；
- 房屋、家具等可能发生晃动；
- 建筑物可能受损或倒塌；
- 需要根据所处环境采取安全行动。

### 4. 重要句型与交际功能

#### 4.1 描述灾害和现场情况
- It rains heavily.
- The wind is strong.
- The waves are big.
- The house is moving.
- The tables and chairs are moving.
- There is a lot of snow.
- The cars could not move.

功能：描述灾害发生时的天气、环境和物体状态。

#### 4.2 描述感受
- I felt worried.
- We felt happy.
- It was wonderful.
- They were tired.

功能：描述灾害经历中的情绪和感受。

#### 4.3 提出安全建议
- You should ...
- You shouldn’t ...
- Go to a safe place.
- Keep away from ...
- Don’t ...
- Use ...

功能：提出应该做或不应该做的安全行动。

#### 4.4 讲述互助经历
讲述灾害中的互助故事时，应说明：
- 灾害是什么；
- 发生了什么；
- 谁遇到了困难；
- 谁提供了帮助；
- 帮助者做了什么；
- 事情结果如何；
- 人物有什么感受。

### 5. 语法与语言规律

#### 5.1 一般过去时：讲述灾害经历
教材故事和人物经历中使用一般过去时。
结构：
- 肯定句：主语 + 动词过去式；
- 否定句：主语 + didn’t + 动词原形；
- 一般疑问句：Did + 主语 + 动词原形 ...?

重点：
- 讲述已经发生的事件时，主要动作使用过去式；
- 不规则动词需要记忆；
- did / didn’t 后使用动词原形。

#### 5.2 be 动词过去式
- am / is → was；
- are → were。
否定形式：
- wasn’t；
- weren’t。

用于描述过去的状态、感受、天气或人物情况。
选择 was / were 时要看主语单复数。

#### 5.3 should / shouldn’t 提出安全建议
结构：
- 主语 + should + 动词原形；
- 主语 + shouldn’t + 动词原形。

功能：
- should 表示应该做；
- shouldn’t 表示不应该做；
- 后接动词原形；
- 建议内容应符合具体灾害场景。

#### 5.4 情态动词与安全表达
教材安全建议常使用祈使句：
- 动词原形开头；
- 否定祈使句使用 Don’t + 动词原形；
- 用于直接、清晰地提醒他人采取行动或避免危险行为。

#### 5.5 故事中的时间顺序
讲述事件时，应按发生顺序组织：
- 灾害发生前或开始时；
- 人物发现情况；
- 人物采取行动；
- 他人提供帮助；
- 事件结束；
- 人物感受或总结。
可使用 then、after that、at last 等顺序表达；若教材原文未出现某表达，出题时应作为拓展处理。

### 6. 阅读与语篇知识
本单元阅读材料包括：
- 暴风雪中的互助故事；
- 地震后的救援经历；
- 人们在自然灾害中互相帮助的故事；
- 灾害发生时的安全行动。

阅读理解重点：
- 灾害类型；
- 发生地点和环境；
- 人物当时的感受；
- 人物遇到的困难；
- 谁提供帮助；
- 帮助行为；
- 事件结果；
- 故事表达的互助精神。

### 7. 安全知识表达边界
本单元的英语学习重点是理解教材中的安全建议和表达方式。涉及现实灾害时，应以当地应急部门、学校和专业人员的最新指引为准。不要把课本中的语言练习当成适用于所有环境的完整应急方案。

### 8. 本单元重点与易错点
- flood、snowstorm、tsunami、earthquake 的词义不可混淆。
- 描述天气和现场情况时，注意 be 动词与主语一致。
- 一般过去时中，肯定句使用过去式；did / didn’t 后使用动词原形。
- was / were 根据主语单复数选择。
- should / shouldn’t 后必须使用动词原形。
- 安全建议必须与灾害场景对应。
- 阅读故事时，要区分人物的感受、行动和事件结果。
- 不能把故事中某个人物的经历误认为所有灾害都会出现的固定情况。

## 二、标准题库

### 1. 考查范围
- 自然灾害名称；
- 灾害特征及现场描述；
- 感受和情绪表达；
- 一般过去时；
- was / were；
- should / shouldn’t；
- 祈使句；
- 灾害故事的时间顺序；
- 互助行为和阅读理解。

### 2. 推荐题型与命题规则
- **灾害词汇匹配**：根据灾害特征匹配名称。
- **情境判断题**：根据教材描述判断对应灾害。
- **词汇拼写题**：考查灾害及相关环境词汇。
- **语法选择题**：考查过去式、was / were 和 should 结构。
- **句型转换题**：考查一般过去时肯定、否定和疑问结构。
- **安全建议题**：根据教材场景选择合理的 should / shouldn’t 或祈使句表达。
- **故事排序题**：按事件发生顺序排列。
- **阅读理解题**：提取人物、灾害、行动、帮助和结果。
- **简短复述题**：按“灾害—困难—帮助—结果”组织语言。

### 3. 答案判定标准
- 灾害词汇与特征对应正确；
- 过去时动词形式正确；
- be 动词与主语一致；
- should / shouldn’t 后使用动词原形；
- 阅读答案有原文依据；
- 故事排序符合原文时间顺序；
- 安全建议符合题目给定情境，不得脱离材料随意发挥。
