# Unit 4 — Time flies!

- 教材印刷页码：25–32
- PDF 页码：34–41
- 单元目标：谈论过去的生活；谈论现在的生活；介绍生活发生的变化。

## 一、教材知识库

### 1. 单元主题与语义范围
本单元围绕过去与现在的生活变化展开，要求学生能够：
- 描述过去某个时期的生活状态；
- 描述过去存在或不存在的事物；
- 描述过去拥有或没有的物品；
- 描述现在的生活状态；
- 比较过去和现在的变化；
- 介绍家乡或生活环境发生的变化。

### 2. 核心词汇与表达
- past：过去；
- now：现在；
- long time ago：很久以前；
- life：生活；
- change：变化；
- ago：以前；
- computer：电脑；
- TV：电视；
- car：汽车；
- bus：公共汽车；
- phone：电话；
- message：信息；
- high-speed train：高速列车；
- travel：旅行；
- send：发送；
- call：打电话；
- free time：空闲时间；
- activity：活动；
- team：队伍；
- goal：进球、目标；
- field：场地。

### 3. 描述过去与现在的生活
本单元的核心对比维度：
- 过去是否有某种物品或设施；
- 过去人们如何出行；
- 过去人们如何联系；
- 过去有哪些娱乐活动；
- 现在有哪些新工具和便利；
- 生活方式发生了哪些变化。

表达时要区分：
- 过去拥有某物：have 的过去形式 had；
- 过去存在某物：there was / there were；
- 现在拥有某物：have / has；
- 现在存在某物：there is / there are。

### 4. 重要句型与交际功能

#### 4.1 描述过去拥有或没有
- People had ...
- People didn’t have ...
- They had ...
- They didn’t have ...

功能：说明过去某个时期人们拥有或没有某种物品、设施或条件。

#### 4.2 描述过去存在或不存在
- There was ...
- There were ...
- There wasn’t ...
- There weren’t ...

功能：说明过去某处存在或不存在某人、某物。

#### 4.3 描述现在拥有或没有
- We have ...
- He / She has ...
- We don’t have ...
- He / She doesn’t have ...

功能：描述现在的拥有情况。

#### 4.4 描述现在存在或不存在
- There is ...
- There are ...
- There isn’t ...
- There aren’t ...

功能：描述现在某处存在或不存在某人、某物。

#### 4.5 比较过去和现在
- In the past, ...
- A long time ago, ...
- Today, ...
- Now, ...
- Today we have ...
- Our life is different today.

功能：组织过去与现在的对比，说明变化。

### 5. 语法与语言规律

#### 5.1 There be 句型：表示某处存在某物
There be 句型强调“某地有某人或某物”，不是表示某人拥有某物。
- There is + 可数名词单数 / 不可数名词；
- There are + 可数名词复数。

一般过去时：
- There was + 可数名词单数 / 不可数名词；
- There were + 可数名词复数。

否定形式：
- There isn’t / There aren’t；
- There wasn’t / There weren’t。

判断重点：
- 根据 be 动词后面的名词单复数选择 is / are 或 was / were；
- There be 句型中的 be 动词与后面的名词保持一致；
- 不要把 There be 与 have / has 混为一谈。

#### 5.2 have / has：表示拥有
一般现在时：
- I / you / we / they have；
- he / she / it has。

一般过去时：
- 各人称统一使用 had。

否定形式：
- don’t have / doesn’t have；
- didn’t have。

关键点：
- doesn’t 后使用 have，不使用 has；
- didn’t 后使用 have，不使用 had；
- have / has 表示拥有，与 There be 表示存在的含义不同。

#### 5.3 一般过去时否定句
结构：主语 + didn’t + 动词原形。
本单元重点用来表达过去没有某种物品或没有做某事。
注意：
- didn’t 已经表示过去和否定；
- 后面的行为动词必须恢复原形；
- 不可写成 didn’t had。

#### 5.4 be 动词过去式
- am / is → was；
- are → were。

否定形式：
- was not → wasn’t；
- were not → weren’t。

使用规则：
- 单数主语或不可数名词通常对应 was；
- 复数主语通常对应 were；
- there was / there were 也遵循相同的单复数规则。

#### 5.5 时间表达
- in the past：在过去；
- a long time ago：很久以前；
- 具体时间 + ago：……以前。
ago 通常与一般过去时连用，表示从现在往前推的一段时间。

### 6. 阅读与语篇知识
本单元阅读材料包括：
- 过去与现在的城市对比；
- 古代与现代生活方式的变化；
- 不同历史时期的活动；
- 过去与现在的交通、通信和娱乐方式。

阅读时关注：
- 时间背景；
- 过去存在或拥有的事物；
- 现在存在或拥有的事物；
- 发生变化的方面；
- 变化带来的生活差异。

### 7. 本单元重点与易错点
- There was / There were 表示“某处有”，have / had 表示“拥有”，不能混用。
- There was 后通常接单数名词或不可数名词；There were 后接复数名词。
- There is / There are 表示现在存在；There was / There were 表示过去存在。
- have / has 表示现在拥有；had 表示过去拥有。
- doesn’t 后使用 have，不使用 has。
- didn’t 后使用动词原形，不使用过去式。
- be 动词过去式 was / were 要根据主语单复数选择。
- 过去与现在对比时，要保证时间背景和动词时态一致。
- ago 表示过去时间，通常与一般过去时搭配。

## 二、标准题库

### 1. 考查范围
- 过去与现在的生活词汇；
- There be 句型；
- There is / are 与 There was / were；
- have / has / had；
- 一般过去时否定句；
- was / were；
- 过去与现在的比较表达；
- 描述生活变化的阅读与写作。

### 2. 推荐题型与命题规则
- **词汇题**：考查生活用品、交通工具和通信方式等词汇。
- **句型选择题**：根据名词单复数和时间背景选择 there be 结构。
- **have 与 there be 辨析题**：考查“拥有”和“存在”的区别。
- **动词形式题**：考查 have / has / had、was / were。
- **句型转换题**：将肯定句转换为否定句，重点考查 didn’t、wasn’t、weren’t。
- **时态判断题**：根据 past、ago、now、today 等信息判断时态。
- **对比阅读题**：提取过去和现在的不同信息。
- **短文写作题**：围绕家乡、交通、通信或生活方式比较过去和现在。

### 3. 答案判定标准
- There be 根据名词单复数和时间背景选择正确形式。
- have / has / had 根据主语和时间背景选择正确形式。
- didn’t 后必须使用动词原形。
- 过去时 be 动词使用 was / were，且与主语一致。
- 对比题必须分别指出过去和现在的信息。
- 写作中时间背景清晰，时态使用一致。
